# ADR-006: IP 分类与溯源优先级决策树

## 状态

已采纳

## 上下文

溯源流水线采集大量 IP 后，需要对 IP 进行自动分类，确定哪些需要深度查询，并按溯源价值排优先级。

## 决策

### 1. 自动分类（Phase 2）

基于规则引擎对 IP 自动分类，规则存储在 JSON 文件中：

```
classifiers/builtin_rules.json    # 内置规则（不可修改）
classifiers/custom_rules.json     # 自定义规则（用户扩展）
```

7 个分类类别：

| 类别 | 说明 | 深度查询 |
|------|------|---------|
| `cloud_provider` | 云服务商 | ✅ |
| `cdn` | CDN/WAF 节点 | ❌ |
| `crawler_scanner` | 爬虫/扫描器 | ❌ |
| `residential` | 家用宽带 | ✅ |
| `invalid_rdns` | 无效 RDNS | ❌ |
| `excluded_domain` | 排除域名 | ❌ |
| `other` | 未识别 | ✅ |

5 种匹配类型：`suffix`、`contains`、`prefix`、`exact`、`regex`

### 2. 溯源优先级（Phase 7 报告分级）

基于决策树的 P1-P4 分级：

```
有反查域名？
├── 是
│   └── 国内 IP？
│       ├── 是 → P1 核心溯源
│       └── 否 → P2 重点溯源
└── 否
    └── 有端口？
        ├── 是
        │   └── 国内 IP？
        │       ├── 是 → P2 重点溯源
        │       └── 否 → P3 辅助溯源
        └── 否
            └── 国内 IP？
                ├── 是 → P3 辅助溯源
                └── 否 → P4 暂缓
```

## 理由

1. **规则驱动** — 分类逻辑通过 JSON 配置，无需改代码
2. **可扩展** — custom_rules.json 支持用户自定义
3. **决策树** — 优先级分级逻辑清晰、可解释
4. **效率** — 非关键 IP 跳过深度查询，节省时间和 API 调用

## 后果

**优势：**
- 自动化程度高，减少人工判断
- 规则热更新（修改 JSON 即生效）
- 溯源优先级帮助分析师聚焦高价值目标

**劣势：**
- 规则匹配基于字符串模式，可能误判
- 自定义规则需要理解规则格式
- 优先级决策树是硬编码的，不可配置
